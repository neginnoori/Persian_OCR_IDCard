# مسیر پیش‌فرض: اصلاح جهت و سپس OCR

در حالت `orientation_only`، DINO/SAM محدوده‌ای برای بررسی جهت پیدا می‌کنند. شواهد متن و چهره بهترین چرخش ۰، ۹۰، ۱۸۰ یا ۲۷۰ درجه را انتخاب می‌کنند. تصویر کامل با همان کیفیت پیکسلی چرخانده می‌شود؛ تبدیل پرسپکتیو یا برش روی خروجی انجام نمی‌شود.

نامطمئن بودن جهت یا نبودن ماسک، فقط هشدار است و Paddle و Hezar همچنان اجرا می‌شوند. خطاهای واقعی نصب، خواندن فایل و اجرای مدل همچنان گزارش خطا دارند. Paddle فقط نواحی متن را پیدا می‌کند و Hezar متن را می‌خواند. کجی دلخواه و پرسپکتیو در این مرحله اصلاح نمی‌شوند؛ برش‌های متن Paddle جداگانه آمادهٔ خواندن می‌شوند.

جدول شش فیلد از جایگاه تقریبی متن نسبت به محدودهٔ کارت ساخته می‌شود و ممکن است نیازمند بررسی باشد. اگر ماسک کارت پیدا نشود، متن خام نمایش داده می‌شود اما فیلدها خالی می‌مانند.

نوت‌بوک جدید را با T4 از ابتدا اجرا کنید. سورس مستقیم از commit درج‌شده دریافت می‌شود و قبل از پردازش، تطابق فایل‌های نصب‌شده بررسی می‌شود. برای رفتار سخت‌گیرانهٔ قبلی می‌توانید `PREPROCESSING = 'rectify'` را انتخاب کنید.
